# Słownik błędów
[source](https://bestrobotvacuum.io/roborock-error-codes) 
### Error 1: LiDAR zablokowany
Usuń włosy, kurz z góry robota, upewnij się że LiDAR obraca się swobodnie.
### Error 2: Zderzak zablokowany
Sprawdź występowanie małych obiektów w zderzaku, sprawdź sprężynę
### Error 3: Koło bez nacisku
Obróć robota, sprawdź okolicę kół, dociśnij koła
### Error 4: Błąd czujnika spadku
Wyczyść czujnik spadku, postaw robota na jasnej powierzchni.
### Error 5: Zablokowana główna szczotka
Wyczyść główną szczotkę.
### Error 6: Zablokowana boczna szczotka
Odkręć i wyczyść boczną szczotkę.
### Error 7: Koło zablokowane
Zwykle mały element stały zablokowany przy kole.
### Error 8: Robot otoczony przeszkodami
Przenieś robota w inne miejsce, sprawdź czujniki.
### Error 9: Brak zbiornika na kurz
Wykrywany magnetycznie, można zakryć czujnik magnesem.
### Error 10: Filtr kurzu mokry lub zablokowany
Zbyt wysokie obroty wentylatora ssącego. Wyczyść filtr.
### Error 11: Wykryte pole magnetyczne
Robot zbyt blisko wirtualnej ściany.
### Error 12: Niski poziom baterii
Naładuj, what are you even doing here.
### Error 13: Błąd ładowania
Występuje po trzech nieudanych próbach w doku.
### Error 14: Błąd baterii
Czujnik temperatury baterii zwraca wartość poza dozwolonym zakresem.
### Error 15: Brudny boczny detektor ścian
Szyba ochronna zabrudzona, przetrzeć.
### Error 16: Robot na nachyleniu
Problem z kalibracją żyroskopu.
### Error 17: Błąd szczotki bocznej
Poważny, sugeruje problem z napędem szczotki.
### Error 18: Błąd wentylatora ssącego
Wentylator nie osiąga oczekiwanej mocy
### Error 21: Błąd zderzaka pionowego
Przycisk pod osłoną LiDAR.
### Error 22: Błąd lokalizacji stacji dokowania 
Brudny nadajnik podczerwieni w stacji dokowania, mało poważny.
### Error 23: Błąd powrotu do stacji dokującej 
Brak sygnału ze stacji dokującej, bardziej poważny.
### Error 24: Robot w strefie bez dostępu
Rutynowy, przenieś robota w dozwolone miejsce.
### Error 26: Brudny boczny detektor ścian
Partrz błąd 15.
### Error 27: Błąd poruszania mopem
Brak możliwości podniesienia/opuszczenia mopa.
#### Nasz robot nie posiada mopa.
### Error 28: Robot na dywanie
Tylko przy mopowaniu 
#### Nasz robot nie posiada mopa.
### Internal Error: Błąd systemu
Sugeruje poważny problem z elektroniką.
